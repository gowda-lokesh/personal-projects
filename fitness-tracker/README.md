# Fitness Tracker

Personal fitness tracker for strength training, cardio and daily steps.

## Stack
- Next.js + TypeScript
- Tailwind CSS
- Supabase Postgres/Auth with RLS
- Vercel deployment target

## Current MVP
- Mobile-friendly workout dashboard
- Date and workout selection
- Custom workout/exercise model in the database
- Set-based strength logging UI
- Data model for cardio and daily activity
- Analytics-ready history schema
